# 3-variable-simultaneous-equation-solver
This script is a personal learning opportunity. I welcome and appreciate criticism.
This project takes a number of simultaneous equations with 3 variables (X Y and Z) and using the Numpy Python library, converts them into matrices and solves. This method uses Gaussian elimination.
While writing this program, I used an exam question as test data, and while the answers were integers, my program outputted floats with a tiny difference. This was caused by a floating point error, and has to do with computers storing real numbers.
